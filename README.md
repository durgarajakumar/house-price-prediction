# house-price-prediction
A Machine Learning mini project that predicts house prices using Linear Regression in Python with Pandas, Scikit-learn, and Matplotlib.
 House Price Prediction using Linear Regression

 Project Overview
This project predicts house prices using the **Linear Regression** algorithm in Python. The model is trained on a housing dataset to estimate house prices based on different features.

 Objectives
- Load the housing dataset
- Perform data preprocessing
- Split the dataset into training and testing sets
- Train a Linear Regression model
- Predict house prices
- Evaluate the model using the R² Score
- Visualize Actual vs Predicted House Prices

 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

 Files Included
- `house_price.py` – Python source code
- `Housing.csv` – Housing dataset
- `README.md` – Project documentation

 Machine Learning Algorithm
